# Git policy

Before committing, review status and scoped diff; exclude unrelated work, secrets, and accidental generated files; confirm validation or document blockers. Determine the branch and avoid publishing directly to `main`/`master` unless explicitly established. Prefer a descriptive feature/fix branch and normal PR workflow.

Create focused commits. Push only when requested or when accepted phases are established to auto-push, and report the branch. Prepare a PR when requested/required; never merge automatically without authorization.
