# Test integrity

Tests are evidence, not obstacles. Never weaken, remove, skip, ignore, or superficially replace checks merely to get green output; never lower coverage or change expectations to accommodate incorrect behavior.

Diagnose whether a failure is implementation-caused, an intentional behavior change, or pre-existing. For intended changes, update tests with equivalent/better coverage and explain why. Add practical regression coverage for bug fixes. Passing tests alone does not prove correctness.
